# Carpeta: Machine Learning

Esta carpeta contiene notebooks que exploran diversos algoritmos y conceptos fundamentales en el campo del Machine Learning, desde modelos lineales hasta redes neuronales profundas y técnicas avanzadas como el Transfer Learning.

## Temas de Estudio

-   **Regresión Lineal:**
    -   Ecuación Normal y métodos de optimización (Descenso de Gradiente por Lotes, Estocástico y Mini-lotes).
    -   Regresión Polinomial para modelar relaciones no lineales.
    -   Curvas de aprendizaje para diagnosticar sesgo y varianza.
    -   Modelos regularizados (Ridge, Lasso, Elastic Net) para prevenir el sobreajuste.
    -   Técnicas de parada temprana (Early Stopping).
-   **Preprocesamiento de Datos:**
    -   Escalado de características (StandardScaler).
    -   Manejo de variables numéricas y categóricas.
-   **Aprendizaje Profundo (Deep Learning):**
    -   Introducción a Redes Neuronales Convolucionales (CNNs) para tareas de visión por computador.
    -   **Transfer Learning:** Utilización de modelos pre-entrenados (como InceptionResNetV2) para acelerar el entrenamiento y mejorar el rendimiento en nuevas tareas de clasificación de imágenes.
    -   Aumento de datos (Data Augmentation) para mejorar la robustez del modelo.
-   **Aplicaciones:**
    -   Análisis de crédito (ejemplo de clasificación).
    -   Clasificación de imágenes.

## Archivos

-   `Clase_RegresionLineal_y_Regularizacion.ipynb`: Cubre los fundamentos de la regresión lineal, descenso de gradiente y técnicas de regularización.
-   `Taller_AnalisisCredito_PreprocesamientoDatos.ipynb`: Taller práctico enfocado en la preparación y escalado de datos para un problema de análisis de crédito.
-   `Clase_Introduccion_TransferLearning_CNN.ipynb`: Introducción al Transfer Learning y su aplicación en la clasificación de imágenes con CNNs.

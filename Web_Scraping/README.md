# Carpeta: Web Scraping

Esta carpeta contiene notebooks dedicados a la extracción de datos de la web, con un enfoque en la adquisición de información meteorológica y su integración con servicios en la nube.

## Temas de Estudio

-   **Extracción de Datos Web:**
    -   Descarga programática de archivos (ej. ZIP) desde URLs.
    -   Procesamiento de archivos descargados (descompresión, manejo de CSV).
-   **Manejo de Datos:**
    -   Carga de datos en DataFrames de Pandas para su exploración y análisis.
-   **Integración con la Nube (AWS):**
    -   Ejemplo de cómo automatizar la ingesta de datos utilizando funciones AWS Lambda y almacenamiento en S3.

## Archivos

-   `Taller_1_Clima_Colombia.ipynb`: Notebook que demuestra la descarga, procesamiento y almacenamiento de datos meteorológicos de Colombia, incluyendo un ejemplo de integración con AWS.

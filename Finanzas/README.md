# Carpeta: Finanzas Cuantitativas y Series de Tiempo

Esta carpeta contiene notebooks enfocados en el análisis y modelado de series de tiempo financieras, utilizando una variedad de técnicas estadísticas y de aprendizaje automático para la predicción y el estudio de la volatilidad.

## Temas de Estudio

-   **Análisis de Series de Tiempo Financieras:** Adquisición de datos de activos financieros, preparación y exploración de series de tiempo (retornos, log-retornos).
-   **Estacionariedad y Transformaciones:** Métodos para identificar y transformar series no estacionarias (logaritmos, diferenciación).
-   **Modelos de Pronóstico Tradicionales:**
    -   **ARIMA (AutoRegressive Integrated Moving Average):** Modelado y predicción de series de tiempo univariadas.
    -   **SARIMA (Seasonal ARIMA):** Extensión de ARIMA para manejar la estacionalidad en los datos.
-   **Modelado de Volatilidad:**
    -   **Modelos GARCH (Generalized Autoregressive Conditional Heteroskedasticity):** Para capturar y pronosticar la volatilidad de las series financieras.
-   **Aprendizaje Profundo para Series de Tiempo:**
    -   **Redes Neuronales Recurrentes (RNN) y LSTM:** Aplicación de arquitecturas de deep learning para la predicción de series financieras.
-   **Herramientas de Análisis:** Funciones de Autocorrelación (ACF) y Autocorrelación Parcial (PACF), pruebas de Dickey-Fuller Aumentada (ADF) para estacionariedad, descomposición estacional.
-   **Evaluación de Modelos:** Métricas como el Error Cuadrático Medio (RMSE).

## Archivos

-   `Modelado_Volatilidad_GARCH_y_Prediccion_RNN.ipynb`: Notebook que explora el modelado de volatilidad con GARCH y la predicción de series financieras usando RNN/LSTM.
-   `Taller_Prediccion_SeriesFinancieras_ARIMA_SARIMA.ipynb`: Taller práctico sobre la predicción de precios de activos financieros utilizando modelos ARIMA y SARIMA.

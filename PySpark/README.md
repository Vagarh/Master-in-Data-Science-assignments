# Carpeta: PySpark

Esta carpeta contiene notebooks dedicados al uso de Apache Spark con Python (PySpark) para el procesamiento y análisis de grandes volúmenes de datos, con un enfoque particular en el procesamiento de lenguaje natural (NLP).

## Temas de Estudio

-   **Configuración de Entorno PySpark:**
    -   Instalación y configuración de PySpark en entornos como Google Colab.
    -   Inicialización de SparkSession y SparkContext.
-   **Operaciones Básicas con DataFrames en PySpark:**
    -   Carga y visualización de datos desde diferentes fuentes (CSV).
    -   Inspección de esquemas y conteo de registros.
    -   Guardado de DataFrames.
-   **Procesamiento de Lenguaje Natural (NLP) con PySpark MLlib:**
    -   Tokenización de texto.
    -   Eliminación de stopwords.
    -   Extracción de características de texto utilizando Bag-of-Words (BoW) y TF-IDF.
-   **Análisis de Datos a Gran Escala:**
    -   Aplicación de PySpark para el análisis de conjuntos de datos extensos, como reseñas de aerolíneas.

## Archivos

-   `PySpark_Setup_GoogleColab.ipynb`: Guía para la configuración inicial de un entorno PySpark en Google Colab.
-   `PySpark_Setup_GoogleColab_Solucion.ipynb`: Solución para la configuración de PySpark en Google Colab.
-   `PySpark_Analisis_Resenas_Aerolineas.ipynb`: Laboratorio sobre el análisis de reseñas de aerolíneas utilizando técnicas de NLP con PySpark.
-   `PySpark_Analisis_Resenas_Aerolineas_Solucion.ipynb`: Solución del laboratorio de análisis de reseñas de aerolíneas.
-   `PySpark_Analisis_Resenas_Aerolineas_Solucion_Variante.ipynb`: Una variante de la solución para el análisis de reseñas de aerolíneas.

# Carpeta: Análisis de Datos

Esta carpeta contiene laboratorios prácticos enfocados en técnicas de análisis y preparación de datos, incluyendo preprocesamiento de texto y análisis estadístico aplicado a casos de negocio.

## Temas de Estudio

- **Preparación y Manipulación de Datos con Pandas:** Carga, inspección y transformación de datos tabulares.
- **Preprocesamiento de Texto con NLTK:** Tokenización, análisis de frecuencia de palabras, eliminación de stopwords, stemming y lematización para la limpieza y normalización de texto.
- **Análisis Estadístico Aplicado:**
    - Pruebas de hipótesis (t-tests) para comparar medias.
    - Cálculo e interpretación de intervalos de confianza.
    - Visualización de datos de series de tiempo para análisis de tendencias y efectos de intervenciones.

## Archivos

- `Lab_PreparacionDatos_y_PreprocesamientoTexto_Colab.ipynb`: Laboratorio sobre preparación de datos y preprocesamiento de texto, configurado para Google Colab.
- `Lab_PreparacionDatos_y_PreprocesamientoTexto_Local.ipynb`: Laboratorio sobre preparación de datos y preprocesamiento de texto, configurado para entorno local.
- `Lab_AnalisisEstadistico_CampanasMarketing.ipynb`: Laboratorio que aplica análisis estadístico (pruebas de hipótesis, intervalos de confianza) para evaluar el impacto de campañas de marketing.

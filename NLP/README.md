# Carpeta: Procesamiento de Lenguaje Natural (NLP)

Esta carpeta contiene una colección de notebooks que cubren una amplia gama de temas en el Procesamiento de Lenguaje Natural, desde las técnicas fundamentales de preprocesamiento de texto hasta modelos avanzados de extracción de características, modelado de temas y predicción de emociones utilizando modelos de Transformers.

## Temas de Estudio

-   **Fundamentos de Preprocesamiento de Texto:**
    -   Tokenización, normalización (minúsculas, eliminación de caracteres especiales).
    -   Limpieza de texto: eliminación de stopwords, stemming (Porter, Lancaster) y lematización (WordNetLemmatizer).
-   **Extracción de Características de Texto:**
    -   Bag-of-Words (BoW) para representar texto como vectores numéricos.
    -   TF-IDF (Term Frequency-Inverse Document Frequency) para ponderar la importancia de las palabras.
-   **Análisis y Visualización de Texto:**
    -   Distribuciones de frecuencia de palabras.
    -   Análisis exploratorio de datos de texto (ej. tweets).
-   **Modelado de Temas (Topic Modeling):**
    -   Latent Dirichlet Allocation (LDA) para descubrir temas abstractos en colecciones de documentos.
    -   Non-Negative Matrix Factorization (NMF) como alternativa para el modelado de temas.
-   **Modelos Avanzados y Deep Learning para NLP:**
    -   Introducción a modelos basados en Transformers para tareas de NLP.
    -   Predicción de emociones en texto utilizando modelos pre-entrenados (ej. DistilRoBERTa).
-   **Herramientas y Frameworks:**
    -   NLTK (Natural Language Toolkit) para diversas tareas de NLP.
    -   Pandas para manipulación de datos.
    -   PySpark para procesamiento de texto a gran escala.
    -   Scikit-learn para extracción de características y modelado.
    -   Gensim y pyLDAvis para modelado de temas.
    -   Hugging Face Transformers para modelos de lenguaje avanzados.
